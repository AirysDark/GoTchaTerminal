◦

3. Build Blockers Summary
•
Total Errors: 0 (Project currently resolves all references and compiles).
•
Total Warnings: ~45
•
Top 5 Critical Risks:
i.
Memory Leak (BLEManager): Singleton holds a Context reference in a static field.
ii.
Memory Leak (FirmwareManager): Singleton holds a Context reference in a static field.
iii.
Deprecated API Usage (BLE): Overriding and using deprecated BluetoothGatt methods (e.g., onCharacteristicRead with byte array parameters instead of modern MTU-safe buffers).
iv.
Inferred Nullability: High risk of NullPointerException on GoTchaUUIDs and IdentityProtocol due to platform call inference without explicit nullability checks.
v.
Redundant Logic: Duplicate state flows in BLEManager (ExtendedBluetoothDevice vs ExtendedDeviceModel) creates synchronization debt.
Root Cause Summary: The architecture-level issues stem from a Transitional State. The project was recently migrated from a monolithic :app structure to a multi-module :core + :ble + :models structure. While compilation blockers are resolved, the cleanup phase (removing duplicated state, fixing memory leaks in new singletons, and migrating to modern BLE APIs) is incomplete.
